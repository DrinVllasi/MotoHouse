# MotoHouse

MotoHouse is a motorcycle showroom app built with React Native and Expo. It lets users browse motorcycles by category and view their specifications and prices.

## Features
- Browse 20 motorcycles across 5 categories
- Filter motorcycles by category
- View motorcycle images, specifications, and prices
- Navigate between screens
- Home screen carousel

## Technologies
- React Native
- Expo
- React Navigation
- JavaScript
- JSON

## Commands to Run the App

npm install
npx expo install react-dom react-native-web @expo/metro-runtime <br>
npx expo install @react-navigation/native @react-navigation/native-stack @react-navigation/bottom-tabs <br>
npx expo install react-native-screens react-native-safe-area-context <br>
npx expo install @expo/vector-icons <br>
npm install react-native-swiper <br>
npx expo start <br>
